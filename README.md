# Director's Bluff - Builds

Download the launcher once:

**https://github.com/MonkeyDHoffy/DirectorsBluff-Releases/releases/latest/download/DirectorsBluffLauncher.exe**

Put it into an empty folder (e.g. `Documents\DirectorsBluff`) and start it. It downloads the game, checks for updates on every start and asks before installing a new version.

Windows 10/11, no extra runtime needed. Online tables: HOST TABLE / JOIN TABLE in the start menu.

This repository only contains finished builds (no source code).
